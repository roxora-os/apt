Roxora apt repository

This is the apt repository of Roxora. It holds Roxora's own packages for installed Roxora systems: hwtool, the wallpapers, the release packages that bring a system to the state of each new Roxora release, and the repository's key. Ubuntu's packages come from the Ubuntu archive, and the kernel and firmware from Armbian's repository, as before.

Images from Roxora 2026.11.5 on have this repository set up. For older images, and for what an update to a new release does, see Updating to a new Roxora release.

Suites

  • noble: Ubuntu 24.04
  • resolute: Ubuntu 26.04
  • stonking: Ubuntu 26.10

One component, main, for arm64.

Signing key

The Release files are signed with the key 0735 3CCF AF21 7254 18E3 CE47 98FC 2BE6 A9A8 952D (Ed25519, "Roxora apt", valid until 2031-11-14): roxora-archive-keyring.asc, or as a binary keyring for Signed-By: roxora-archive-keyring.gpg. The package roxora-archive-keyring installs it as /usr/share/keyrings/roxora-archive-keyring.gpg.

Source and workflow: roxora-os/apt.
